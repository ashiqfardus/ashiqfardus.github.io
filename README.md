# Md. Asikul Islam - Software Engineer Resume

This repository hosts my professional resume, built with HTML/CSS and optimised for ATS and print-to-PDF.

**Live View:** [ashiqfardus.github.io](https://ashiqfardus.github.io/)

## Features

- **Responsive Layout:** Clean two-column design.
- **Print Optimized:** Stylesheet (`@media print`) adjusted to fit perfectly on a single A4 page.
- **Open Source Packages:** Highlights my Laravel packages `laravel-fuzzy-search` and `horizon-running-jobs`.

## generating PDF

To generate the PDF version:

1. Open `index.html` in a browser.
2. Press `Ctrl+P` (or Cmd+P).
3. Save as PDF.
